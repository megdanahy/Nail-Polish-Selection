# [Nail Polish Decisions Maker](Nail_Polish_Project.py)

## Overview
I'm very indecisive when it comes to choosing a nail polish color, so this is supposed to help me choose when I can't decide alone.


## What is it
This is a decision tree that makes it so the computer can pick my nail polish color according to various factors!
It goes down a decision tree to account for season, vibe, and general likes/dislikes so I can choose the best nail color for the week.
